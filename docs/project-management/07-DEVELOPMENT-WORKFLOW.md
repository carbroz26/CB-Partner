# CB-Partner — Development Workflow

Status: PROPOSED

Standard lifecycle:
1. IDEA — capture desired outcome.
2. DISCUSS — clarify requirements and constraints.
3. RESEARCH — gather evidence when needed.
4. DECIDE — select direction.
5. DECISION FREEZE — record accepted decision.
6. PLAN — inspect code and create implementation contract.
7. PLAN FREEZE — user approves contract.
8. TRELLO — create/update task.
9. BRANCH — create focused branch.
10. IMPLEMENT — follow frozen plan.
11. TEST — run relevant checks.
12. REVIEW — compare implementation with plan/rules.
13. ACCEPT — resolve required findings.
14. CODE FREEZE — no unrelated improvements.
15. COMMIT/MERGE — logical Git history.
16. DOCUMENT — update authoritative documents.
17. CHECKPOINT — record known-good state.

Personal rule: when tempted to restart, first perform a focused fix/migration assessment.
