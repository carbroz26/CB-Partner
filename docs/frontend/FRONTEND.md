# CB-Partner — Frontend Engineering Guide

Status: PROPOSED

Purpose: Frontend conventions complementary to architecture.

UI direction: Compose Multiplatform.

Principles: UI renders state; user interaction emits events; business rules do not live in composables; reuse components when reuse is real; avoid premature abstraction; accessibility and responsive behavior are part of completion where applicable; platform-specific behavior stays localized.

State follows Store/MVI/UDF. No ViewModel.

Future conventions to finalize: design system, navigation, screen/component organization, resources, localization, accessibility, UI testing, previews, and theming.
